## 修正内容

1. PostgreSQL JSONB 会调整对象字段顺序，并省略 JSON 中不能表示的可选值。联动服务、电脑原文整理和 v2 记忆/上下文输出原来使用字符串序列化结果比较，导致原文不变时仍更新版本，离线重放也可能产生假冲突。改为按实际 JSON 数据比较，忽略对象字段顺序和省略字段；仍区分数组顺序、值的类型、null、内容变化和删除。
2. 后台记忆整理中的联系人风格和全局风格原来按原始字段顺序计算摘要，导致重复整理时不断增加版本，并把新版本同步到手机。共用同一 JSON 比较方法；没有新样本或实际变化时不更新风格记录，实际编辑、来源失效和保留期限变化仍按原规则处理。
3. 手机重新关联联系人后，解除关联的旧资料继续保留。网页为这类记录增加「旧关联」「已解除关联，保留旧资料」说明，避免将同名旧档案当成当前连接。不删除旧资料，也不改变联系人或额度。

共用比较方法位于 `packages/infrastructure/json-value.mts`。没有修改手机模型配置、上传手机密钥或重新安装手机应用；此次手机端无需升级 APK。
