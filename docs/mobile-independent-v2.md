# 手机独立生成与电脑资料同步（2026-10-12）

本方案依据本人最新明确要求：手机只辅助聊天，每次生成三条候选，由本人自行粘贴发送；两端通过聊天记录与长期记忆联动，手机按照与电脑一致的流程独立生成。替代此前“手机把本轮内容发给电脑生成”的提议。

## 运行方式

手机：获取截图或当前可见聊天 → 整理有来源的消息 → 更新本地记录 → 构建上下文 → 低成本模型独立决策 → 按场景选择低成本/高档模型 → 一次生成三条候选 → 本地质量检查 → 展示、编辑、复制。截图理解属于输入处理，不与决策或最终生成混为同一阶段；文字场景无需图片处理。

电脑：接收平台消息并运行自身的 v2 流程，维护长期记忆、表达习惯和复杂管理功能，可建设自动回复模式。当前真实 QQ 候选试用仍只生成候选，没有启用自动发送。两端模型调用在各自设备发起，手机起草不依赖电脑在线。

同流程指相同处理阶段、13字段决策契约、风险路由和保守质量原则；Android 使用本地数据结构和检查实现，不能宣称两端所有模型结果或规则逐字相同，不要求 Android 使用桌面 PostgreSQL 或共用电脑生成任务。手机任务不包含平台发送步骤；复制与生成不记为实际发言。

## 数据同步

| 方向 | 内容 | 使用方式 |
| --- | --- | --- |
| 手机到电脑 | 截图识别/主动读取产生的聊天原文、说话人、时间、来源和不确定标记 | 作为历史资料入库，供上下文与记忆整理使用 |
| 电脑到手机 | 长期记忆、已确认关系、回复边界、偏好、表达样例及必要背景 | 缓存到本机，按当前话题检索并构建上下文 |
| 两端更新 | 原文纠正、版本与删除记录、冲突处理结果 | 保留双方修改，以版本确认替代按时间静默覆盖 |

本人明确关联对象和平台。消息去重依据来源、说话人、时间及连续重叠，不能只按相同文字去重。同步到电脑的历史记录不作为实时来信触发电脑自动发送。手机未发送候选与手工草稿不作为既有聊天记录上传；“我已发送”保留人工确认的来源，不能冒充平台送达证据。

电脑 v2 记忆同步保留 ID、版本、类型、主体、内容、证据来源与版本、证据性质、状态、有效期、重要性、置信度及锁定信息。手机只将当前有效且允许使用的记忆加入确定事实；待确认、过期、删除或被替代内容不能继续当事实使用。不以无来源摘要代替完整记忆。候选绑定本地会话修订，同步改变相关上下文时使旧候选过期，手工文本仍可保留供核对。

同步默认传输识别记录与必要图片说明，原图留在本次处理缓存；模型密钥继续在各端私有存储。支持离线待同步、重连续传、成功时间显示、删除同步与显式冲突选择。电脑关机只影响资料更新，不影响手机使用已有资料生成；手机没网络时保留本轮内容和手工稿。

## 手机生成规则

- 本地检索近期消息、较早背景、有效长期记忆、已确认关系、边界和可靠表达样例，并按预算裁剪。同步的是资料，手机自己组装本轮上下文。
- 低成本模型决定当前回应动作、策略与风险；采用与桌面一致的决策结构和路由条件。日常回复使用低成本模型，复杂场景使用本人配置的高档模型。
- 需要回复时选定生成模型一次产出三条不同思路的候选，不先生成低档再无条件生成高档。关键背景不足时明确提示补充，不编造三条事实回复。
- 本地检查结构、长度、事实和边界；候选可编辑、重写，手机没有自动填入或发送步骤。各端独立配置密钥，低成本/高档/识图接口可分别配置，提供每日调用及预估 token 上限。
- 0.7.1 后续已经接入离线额度分配与各端持久计量，电脑离线时手机使用已领取额度。普通入口与 QQ 候选入口分别沿用各自账本，不自动迁移离线额度；本方案不扩大既有费用授权，进一步的费用功能按最新要求延后。

## 本轮完成（0.7.0）

- 复用 `packages/link` 的配对、HTTPS 证书绑定、增量游标、冲突和离线缓存，新增电脑只读 `memory_v2/context_v2` 记录。记忆按所有者、账号、联系人、会话隔离，包含完整类型、证据、版本、有效期和状态。
- 手机原文进入电脑 `data_messages` 的 `import` 模式；新增、纠正与删除会使相关证据和上下文失效，但不会走平台实时入站或创建回复任务。重复同步不会重复导入。后台按批读取已导入来源，避免逐条重复查询。
- 手机本地按当前话题检索有效记忆；保留本轮消息、明确边界和锁定承诺，按预算裁剪较早资料。过期、停用或来源失效的记忆不参与生成，同步变化使旧候选失效。
- 实际生成按钮已接入识别→上下文→决策→路由→三候选→本地检查。截图识别先保存；重试/改写复用已识别文字。文字通常两次模型请求，首次截图通常三次；wait/skip/ask_user 不请求生成模型。
- 日常采用低成本模型；高风险采用已配置的高档模型。未配置高档时明确提示使用低成本模型核对；已配置的高档接口失败时不静默改用低档或重试。
- 手机密钥加密存于本机，不同步；每日调用与预估 token 在请求前持久记录，失败/重启不返还。0.7.1 补入模型价格、费用预留与调用记录；后续已补齐普通 Core/QQ/微信共享账本接线，支持离线额度分配和汇总，见[费用指南](unified-budget.md)。原费用上限不扩大，旧实例需统一更新生效。
- 本地检查覆盖长度、本人事实、敏感承诺、隐私、边界、AI否认、内部流程泄露与明确风格要求；编辑后重新检查。手机仍只允许复制并人工粘贴发送。

当前 QQ 候选工作台已启用同步，范围限定到此前授权的两位试用好友。具体设置与证据见[交付报告](reports/mobile-independent-v2-2026-10-12.md)。
