# P4-3 真实图片/语音 provider 与独立限额

2026-10-03 开工并当日完成门禁，分支沿用 `task/P4-2-media-persistence`。范围按 [总控范围审定](P4-3-proposal-2026-10-03.md)，本人于开工前确认；媒体日限额默认值（图片/语音各 200 次、各 200k token）亦由本人选定。本卡只做离线开发：**没有调用任何真实模型、没有产生费用、没有取微信原文件、没有真实发送**，也没有新增迁移或依赖（0013 仍未分配）。

## 交付

### 图片真实 adapter（新增 `packages/ai/understanding/vision-provider.mts`）

- 实现现有 `BinaryMediaProvider`：只接收单个已校验媒体的字节、`mediaType`、MIME 与取消信号；看不到联系人、消息 ID、路径、策略或其他消息；不判断是否允许发送。
- 请求为 OpenAI 兼容 chat completions：图片以 base64 `data:` URL 内联，且**只出现在 `user` 消息里**（供应商文档的硬限制）。`response_format=json_object`、`stream=false`，usage 回填 token。
- **格式按字节判定**（`understanding/image-format.mts`：PNG/JPEG/GIF/WebP），声明 MIME 与内容不符直接 `MEDIA_UNCERTAIN` 拒绝，不改标、不转发。上限：单文件 10 MiB、内联 24 MiB、请求体 40 MiB；`detail` 仅 `low/high/original/auto`，默认 `original`（`low` 会缩放，不足以支撑 `full_image`）。baseUrl 必须 https、不得带凭据/查询/片段。
- 返回结构化解释：非空正文、`completeness=complete`、`visualCoverage=full_image`、不确定性、`criticalUnclear`。模型未给 `uncertainty` 时记为「模型未声明不确定性」，不当作确定；`criticalUnclear=true` 仍由既有 gateway 转人工。
- 失败分类：HTTP 非 2xx → `DEEPSEEK_HTTP_<status>`（带供应商错误码，不带正文）；空文本/结构无效/超长 JSON → `MODEL_UNAVAILABLE`；字节或格式不符 → `MEDIA_UNCERTAIN`；非图片类型 → `UNSUPPORTED_CAPABILITY`。错误文本不含密钥、字节或正文。

### 语音通用 adapter（新增 `packages/ai/understanding/voice-provider.mts`）

- OpenAI 兼容 multipart `/audio/transcriptions`，容器白名单见 `SUPPORTED_AUDIO_FORMATS`（mpeg/mp4/x-m4a/wav/x-wav/webm/ogg/flac），可选两位小写 `language`。
- **本仓库不声明任何供应商支持语音转写**：未显式配置端点即语音支持列表为空，语音继续转人工。这是失败关闭，不是缺失实现。
- 空转写、非 JSON、超长 → `MODEL_UNAVAILABLE`；未支持的容器或媒体类型 → `UNSUPPORTED_CAPABILITY`。成功时给出 `transcriptCoverage=complete` 与明确的不确定性说明（音色/情绪/说话人身份均未核实）。

### 证据与观测边界

两个 adapter 都返回一个结构占位 `evidenceRefs`，`interpretContextMedia` 会丢弃它并换成由可信消息绑定与文件哈希构造的证据——**模型自报引用永远不会成为证据**。新增单测断言最终 `evidenceRefs` 等于 `['<account>:<platformMessageId>', 'media:<id>:<sha256>']`。观测通道未改：只有版本、匿名快照/调用标识、类型、结果、token 与时延。同时给 `adaptDataContextProjection` 的持久解释分支补上正文非空校验与非空 `evidenceRefs`，使上游证据被清空的脏投影在 04 侧显式失败而不是被静默接受。

### 独立限额（`packages/ai/understanding/media-budget.mts`）

- `withMediaDailyBudget` 按 UTC 日、**按媒体类型分别**计调用与 token：图片耗尽不影响语音，两者都不占用文本限额（文本仍是 `generation/model-budget.mts`）。
- 超出抛 `MODEL_BUDGET_EXHAUSTED` → 04 映射 `MODEL_UNAVAILABLE` → 02 转人工；与文本闸一样是**进程内失控闸**：重启清零，不是月预算，也不是账单上限。默认各 200 次、各 200k token（本人 2026-10-03 确认）。
- 调用计入「尝试」：超时或供应商报错也算一次付费尝试。

### 显式装配与配置面（`packages/ai/understanding/media-env.mts`、`apps/core/config.mts`）

- `MEDIA_VISION_ENABLED` / `MEDIA_VOICE_ENABLED` 默认关闭；关闭时工厂返回 `null`，不会误当成「已就绪」。
- 开启需要 `MEDIA_API_KEY`（或按类型的 `MEDIA_VISION_API_KEY`/`MEDIA_VOICE_API_KEY`）；**不会回退到 `DEEPSEEK_API_KEY`**，文本密钥不能顺手解锁媒体付费调用（有负测）。开启语音还必须有 `MEDIA_VOICE_ENDPOINT` 与 `MEDIA_VOICE_MODEL`。
- 半配置或非法取值（缺密钥/缺端点/非法 detail/非法限额）让核心进程**启动即失败**；四项限额即使类型关闭也会校验，避免错配置藏到开关打开那天。
- 核心组合根当前**没有媒体路径**，所以这里只做配置校验与 `mediaImageEnabled/mediaVoiceEnabled/mediaVisionModelId` 三个安全字段；生产媒体仍转人工。
