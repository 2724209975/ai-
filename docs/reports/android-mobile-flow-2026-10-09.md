# 手机回复体验 0.5.0（2026-10-09）

第一批与第二批合并完成，以手机顺手操作为主。版本 `0.5.0` / `versionCode 15`。相关功能全部写完后统一构建、测试和检查；未扩展电脑自动回复。

## 交付行为

1. **面板和键盘**：悬浮面板默认屏幕高度约52%，顶部横条可拖动至38%～78%并保存；键盘出现时按实际可见区域调整面板，为底部操作留白。编辑期间隐藏截屏／读取入口，底部填入、复制、完成编辑固定保留。较长候选仍通过中间内容区滚动阅读。
2. **继续原来的操作**：按对象保存阅读位置、编辑、最近记录、更多和重写展开状态。同次 App 运行中，收起再开、切换对象和查看记录返回可以继续处理；仅滚动而没有修改内容也保存位置。界面位置保存在内存；每条候选的手工文本随档案落盘，进程重启后可以恢复。
3. **等待、取消与重试**：显示实际处理阶段及等待秒数，支持取消请求；保留本轮截图和已有草稿，重试不用重新获取来源。视觉流程仍是一次模型请求同时识别与起草，未增加串行调用。
4. **上下文衔接**：面板直接显示对象平台、最近保存的一条发言、本轮来源状态和已有资料的同步时间。最近记录可展开，完整记录查看后返回不清除编辑状态。这里显示已经获取／同步的内容，不代表完整聊天软件历史。
5. **候选和个人表达**：请求三种不同回应策略及对应短标签，第一条优先给当前情境最合适的回复；其余采用不同接话思路，避免只替换同义词。重写携带当前未发送文本，要求保留本人修改的意图和关键信息。可靠本人对话示例按当前话题相关性选取，其次按最近顺序；AI内容、识别不确定和顺序不确定的样例不参与学习。

## 仍需实际使用判断

本轮没有连接目标红米手机，澎湃系统的键盘、悬浮权限、后台限制及真实微信／QQ填写仍需手机试用。本轮验证了模型输入、解析和操作链路，未重新验证真实模型的自然度、候选差异或生成速度；这些效果由实际聊天场景和本人配置模型决定。

电脑同步协议、聊天软件接入和实际发送规则保持现有实现；电脑自动回复继续低优先级。
