# P4-5a 语音数据库候选离线边界验证范围审定

总控依据本人“继续完成下一环节”及 P4-5 只读复核，审定先完成离线候选，不启用真实获取。当前 `GetVoiceBuffByMsgId` 使用通用 Select 后直接取第二行；Select 丢失类型信息，ExecSelect 忽略 step/finalize 错误，不能作为安全原文件接口。

本卡新增可复用 C++ 查询内核及独立补丁，绕开通用 Select：仅接受规范十进制、正的 SQLite int64 消息 ID；仅读取调用方给定的已知 MediaMSG 数据库句柄快照，最多 64 个、不得重复；每库最多两行，要求全体恰好一个非空 BLOB；复制前检查 2 MiB 上限，按明确字节长度复制，拒绝 NULL/文本/多匹配及 prepare/step/finalize 错误。只返回固定状态，不输出 ID、SQL、数据库原始错误或字节。严格类型与上限是实验候选规则，不代表真实微信 schema 已验收。

补丁由离线测试在合成源码副本上验证应用。查询内核使用与固定 helper 一致的函数签名，测试包含故障注入及真实 SQLite 合成数据库。Windows 本机测试使用已有 MSVC 和系统 SQLite DLL；其他开发机可用 C++17 编译器和系统 SQLite，无新增 npm/编解码依赖。工具链缺失报失败，不 skip。不会访问真实数据库或调用微信地址。

可改路径：`scripts/wxhelper-voice-db/`、`scripts/wxhelper-voice-db.test.mts`、`scripts/wxhelper-voice-db.patch`、本报告/交付报告、开发计划。补丁默认编译关闭；不接 HTTP/service、不改登记过的私有源码树或 DLL、不改平台能力快照/运行配置、不新增迁移或公共契约。下一卡再准备独立 helper 构建及接收验收流程；真实平台操作由本人执行，容器/转码/ASR 仍另行审定。

验收覆盖旧函数越界复现、精度与注入拒绝、空结果、错误退出与释放、列/类型/长度/指针边界、NUL/全部字节保真、跨库歧义、句柄快照边界、真实 SQLite 查询、补丁默认关闭及可应用性。完成后跑完整 PostgreSQL/浏览器门禁，0 fail、0 skip。
