## 电脑填写

1. 打开 [本机工作台](http://127.0.0.1:55135/#chat)，登录并选一个联系人，打开「聊天设置」。
2. 「低成本模型配置」预填 `qwen3.7-flash`，「高档模型配置」预填 `qwen3.5-plus`。使用北京地域百炼 API Key；如控制台给出专属接口基础地址，可替换预填地址。
3. 在每组分别填写密钥，点击「保存低成本模型配置」或「保存高档模型配置」，再点击该组「启用已保存配置」。等待状态显示已启用后，再操作另一组。
4. 同一个北京地域百炼账号可以在两组填写相同 Key。密钥不回显、不存入浏览器本地存储；更换供应商或接口必须重新填写密钥，不沿用其他接口的旧 Key。

保存只写私有草稿；启用加载不可变配置快照并重启服务。后续改草稿不会自动生效。低档用于分类、日常回复和 QQ 图片理解；高档用于旧引擎的复杂回复，并已注册为四级引擎可选分析模型。四级决策引擎仍默认关闭，不能将接口配置完成当作模型效果验收。

## 手机填写

安装包：[reply-assistant-0.8.1-debug.apk](../output/android/reply-assistant-0.8.1-debug.apk)。覆盖安装，保留原资料和配对。

在「设置」点击「填入千问省钱配置」，展开低成本模型填写百炼 Key，点击「复用低成本密钥到识图与高档」，最后「保存设置」。三档地址须相同，复用按钮才可用。模型密钥仍只在手机加密存储，不从电脑同步。手机低档兼作识图和决策，复杂回复使用高档；手机没有四级分析升级，本轮只增加千问参数与预设适配。

快速回复时，官方千问支持型号使用 `enable_thinking=false`，DeepSeek 仍使用 `thinking.type=disabled`。兼容基础地址 `/compatible-mode/v1/` 会自动追加 `chat/completions`，完整请求地址保持原样。
