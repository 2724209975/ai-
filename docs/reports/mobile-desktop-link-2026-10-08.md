# 手机与电脑联动首版交付（0.4.0）

已安装到红米 K80 Ultra，覆盖升级保留原有模型配置和聊天档案。手机已与当前电脑完成配对；尚未替用户选择或关联真实聊天对象。

## 使用

1. 手机进入「设置 → 连接电脑 / 同步资料」。对需要同步的档案，选择对应电脑联系人，点击「关联此对象」。同名联系人显示所属平台；也可以选择「仅整理当前手机资料」。临时聊天不参与同步。
2. 电脑进入「更多 → 手机联动」，查看近期聊天、整理结果，编辑对象的关系说明、回复风格、已保存偏好和已授权的关系背景。
3. 手机打开 App、回复面板或修改本地档案后尝试同步。联动设置展开时每三十秒检查一次；可点「立即同步」。电脑不可达时保留已下载资料，稍后续传。
4. 同一项资料被两端同时修改时保留两个版本，主动选择后再合并。没有采用的候选、手工草稿、咨询记录和原始截图均不上传电脑。

电脑关闭后，手机继续使用已同步的上下文和风格资料；生成回复仍需手机联网访问用户配置的模型服务。截图、三条候选、复制和填写操作沿用原来的手机流程。

## 本次能力

- 一次有效的两分钟配对码、二维码及粘贴入口；HTTPS 证书绑定，电脑保存设备凭据摘要，手机加密保存连接凭据。电脑可撤销设备连接。
- 按用户选择的对象同步确认聊天、风格样例、偏好和已授权背景；双平台电脑数据库分别读取，平台与联系人共同确定归属。
- 原文、来源、版本和删除标记随增量同步保留；重复提交不会重复入库。解除关联停止后续同步，保留已下载资料；删除关联档案的请求可离线排队。
- 电脑整理最近原文、较早有来源的摘录及表达习惯。至少十条可靠表达才使用统计，最多八组示例；AI 草稿、不确定或未标记的截图表达不用于学习。
- 电脑模型启用时可选择有用的较早原文，返回的来源必须属于输入，不直接把模型编造的摘要当作事实。此调用共用现有电脑模型预算，模型关闭、失败或预算不足时保留原文摘录。
- 每批电脑原文只重新整理一次，避免大量历史逐条整理；手机只写入改变的档案。同步返回前检查对象、聊天、偏好及连接状态，手工草稿保留，旧结果不能覆盖后来修改。
- 联动使用独立数据库表，手机资料不会注入平台收件、发送任务或事件出队流程，不触发回复或实际发送。

## 部署

用户快捷方式实际运行 `.local-workspace-release`，它包含当前源目录之外的已部署功能。本次选择性合入联动模块，保留账号、模型、关系工具及私有配置。源目录迁移为 `0014_mobile_link.sql`；实际运行目录按既有迁移顺序使用 `0016_mobile_link.sql`。

电脑页面为 `http://127.0.0.1:8790/#link`；手机使用局域网 HTTPS 8791 端口。当前红米经真实 Wi-Fi 请求验证可达，无需新增防火墙规则。电脑地址改变时重新运行联动配置并生成配对码。

`scripts/deploy-mobile-link.py` 可重复选择性部署；`scripts/enable-mobile-link.ps1` 配置证书和局域网地址。模型 Key 不参与同步，证书私钥和配对配置位于忽略目录。

## 首版边界

仅同一局域网；首版手动关联对象，不按昵称自动合并。电脑资料变动通过前台检查或立即同步更新到手机。长上下文先提供有来源摘录；模型筛选的内容仍是原文，不宣称已完成全面关系理解。

历史导入的新工具、通用 Skill 编辑器、完整咨询跨端续聊、远程公网联动与自动备份仍属于后续工作。
