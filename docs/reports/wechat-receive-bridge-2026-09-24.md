# 微信 wxhelper 只接收桥接：持久化与实时入站

日期：2026-09-24。本轮范围是把前次已实测的 wxhelper 推送接入 `packages/platform/wechat`、`apps/bridge` 和 PostgreSQL 接收门禁；**没有实现或调用微信发送接口**。旧版[平台能力快照](platform-wechat-capability-snapshot-2026-09-24.json)保留为当时的原始记录：`receive_types=tested`，其余能力族和总体状态仍为 `unknown`。本报告补充接入证据，不把平台侧收到了推送等同于媒体完整、历史补齐或关机运行。

## 实现与安全边界

- 入站只监听 `127.0.0.1`，检查私密回调令牌、请求方法/路径、消息体大小、目标测试账号；生产用 `POST /wxhelper/event?token=<private>`。本机已安装的 `config.ini` 无写权限，本轮由一个只监听回环的临时转接进程接住原 `19099` 回调，再将原字节送入 `19098` 上的令牌入口；原配置未改变。正式宿主需把 wxhelper 回调直接指向受保护入口，且始终不对公网开放。
- `msgId` 是 18–19 位整数，解码器在 `JSON.parse` 前保留顶层原始数字词法，避免精度丢失；`fromUser/toUser` 与已登记自账号核对。来自自账号的推送保留私密原始字节并在同一接收事务暂停账号，不冒充好友消息。群聊与名单外联系人只记最小发现元数据和摘要，不保留聊天正文。
- 对登记好友：原始字节私密落盘，`platform_inbox_raw` 去重与 `event_outbox` 写入同一事务，随后 02 消费；消费失败的事件可由 outbox pump 重投。图片、语音及未知类型保留原类型并要求人工处理；没有原媒体获取证据，不声称完整。
- 微信组合根没有 worker 和发送传输；即使出现待确认方案，本轮也不会向微信发消息。

## 验证结果

1. **合成事件 + 真实 PostgreSQL/HTTP 集成测试**：令牌错误拒绝；18–19 位 ID 精确保留；重复推送只处理一次；同 ID 改正文返回冲突；名单外与群聊无业务消息；本人方向事件账号暂停；发送任务 0；原始文件与 DB 引用一致。`tests/integration/postgres-wechat-bridge.test.mts` 通过。这是工程验证，不是平台实况。
2. **前次真实推送的离线重放**：在新隔离库中通过新 HTTP 入口重放私有目录的 5 条真实 wxhelper 原始字节，再重放其中 1 条重复。5 条 inbox、4 条好友消息、1 条本人方向隔离，平台 ID 逐条精确保留；重复没有第二份业务消息，发送任务与待处理平台 outbox 均为 0；5 个私有原始文件无孤儿。此项使用历史样本，不能算新的实时平台事件。
3. **本轮新的实时推送**：固定本机微信客户端二进制 SHA-256 `2058A926…` 与已移植 `wxhelper.dll` SHA-256 `F67EFF42…`，均与前次成功实验一致。测试号登录后只调用 `checkLogin`（`code=1`）、`hookSyncMsg`（`code=0`）；知情测试好友从原客户端手发 1 条无私人信息的文字。新桥接保存 **1 条**该好友真实原始事件，02 数据表新增 **1 条 text 消息**，平台 ID 与原始推送精确相同。另有 15 条不在登记范围的回调仅留发现元数据，未保存其正文。发送任务 0、平台 outbox 待处理 0、私有原始文件 1 且无孤儿；微信进程仍运行。采样后 `unhookSyncMsg` 返回 `code=0`，临时转接和桥接已停止。

前次与本次原始字节、私有令牌、账号/好友标识及本地日志都留在 gitignored 目录；仓库只保留去敏计数与字段相等结论。完整本机 `npm run verify` 在隔离 PostgreSQL 17.11 上通过：**212 unit、9 contract、27 PostgreSQL integration、13 E2E 与网页构建，0 fail/skip**。首轮因旧 outbox pump 合成夹具未填 `platform` 而有 1 项失败；夹具补齐 QQ 平台字段后单项复跑和完整门禁均通过。完整输出私留在 gitignored 的 `.local-wechat-spike/verify-bridge-final-20260924.log`。

## 剩余门槛

真实接收链路已接入本机工程，但 wxhelper 回调本身**没有平台签名**；回环 + 私密 URL 令牌是本项目的本地边界，临时转接只用于这次原配置不可写的验证，不能作为生产部署。仍需在独立 Windows 宿主上固定客户端/移植 DLL、直接配置私密回调、做断线与重启补齐及 AC23。发送偏移、回执、本人/系统区分、原图/原语音/表情完整性和历史同步均未验证；微信自动发送继续关闭。
