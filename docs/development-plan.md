## 4. 验收记录规则

每条 AC 记录 `not-run/pass/fail/blocked`，环境 `unit/integration/mock-e2e/wechat-real/qq-real`，代码 commit、契约版本、数据夹具、步骤、期望/实际、日志 correlationId、截图/回执和已知限制。`pass(mock-e2e)` 不能汇总为平台通过；平台能力不足应为 blocked 或 fail，不能改期望来通过。

权限、隔离、重复、旧方案、接管、暂停、未知发送类用例必须全过才可对任何联系人开启自动模式。初次真实运行只选择少量联系人、确认模式；本人逐个评审后启用自动。回滚方式是全局暂停、停止 worker dispatch、保留入站和审计，再恢复上一可用镜像；数据库回滚不能丢已提交发送事实。
