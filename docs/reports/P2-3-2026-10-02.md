## 回放用法

默认离线 fake，工具不连接数据库、平台或发送端口。已提供可直接运行的合成样本：

```powershell
node packages/ai/eval/prompt-replay.mts --samples packages/ai/eval/samples/synthetic-text.json
```

默认比较两个登记版本。stdout 只含样本序号、版本、固定状态、候选数量/分条长度和截断数量；不输出样本正文、身份、候选正文或密钥。

本人需要查看/盲评候选时，显式增加 `--private-candidates <本机私有新文件>`，候选仅写入该文件；目标已存在则拒绝覆盖。真实授权样本与结果保存在本机受控目录，不提交仓库。示例文件是纯合成数据，没有真实身份。

样本根对象为 `schemaVersion:1`、`authorization` 和 `samples`。授权须含 `ownerAuthorized:true`、`deidentified:true`；真实模型还需 `externalModelAuthorized:true`。每个样本含 `cutoffTime`、`cutoffMessageId`、历史 `policy`、`messages`、`facts`，完整格式见合成样本和 `replay-samples.mts`。消息只用 m1/m2 等本地序号及 owner/contact/agent；事实只用 f1 等序号，另列 version、recordedAt、confirmedAt、有效区间、确认/删除状态和消息证据。额外字段、摘要、分析、平台事件、真实 ID 等拒绝。

消息按时间和原数组顺序截断到触发消息，同时间但排在触发之后的历史回复也不进入输入。事实先选截止时已记录的版本，再核验确认/有效时间、删除状态和所有证据是否可见；后续纠正、后续确认、过期事实和未来证据不进入输入。策略须声明截止前有效。所有输入消息设为 replay，仍通过原有 04 事实/风险检查，不给发送授权。

真实 DeepSeek 入口只能由本人明确在场执行，并同时满足样本外发授权、CLI `--provider deepseek --allow-paid --max-calls <正整数> --max-tokens <正整数>` 和现有 DeepSeek 环境配置；仅设置密钥不会切换 provider。两版本/全部样本共用单次运行计数，还保留现有日预算守护，输出长度限制 256 token。失败或用量缺失耗尽剩余运行预算，reportedTokens 保留未知，不把预算预留当实际用量。

预算在请求前检查、用量在请求后得知，单次响应可能超出剩余 token 限额；这不是供应商账单的硬上限。进程重启会重置单次运行计数，不能替代月度费用上限。没有明确付费授权时只运行 fake。

fake 两版本会得到同样的确定性候选，检验的是模板选择、截断与检查链路，不证明 v2 质量更好。真实候选须由本人盲评；本次没有质量评分或 D08 判定。
