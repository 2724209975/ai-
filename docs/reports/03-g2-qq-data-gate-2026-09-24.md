## G2 数据边界结论

1. 入站原始字节先进入私有文件与 `platform_inbox_raw`，接受事件的 outbox 先提交；随后 02 在自己的事务里调用 03 provider 写消息、失效旧快照、更新 epoch 和控制。重复同一平台键不会再次运行 02。`provenance.rawEventRef` 是 `bridge:{accountId}:{sha256 前 32 位}`，可与原始记录的完整 `payload_sha256` 核对；它不是 `payload_ref` 文件路径，消费方不能把它当路径读取。
2. provider 的联系人查询隔离、事实来源拒绝规则与受限角色 RLS 用例通过。未登记对端仍只有原始发现记录，既有 `tests/integration/postgres-qq-bridge.test.mts` 覆盖无任务/无发送。新门禁固定了已登记联系人重放和相同键不同正文的控制状态不变式。
3. 对端不可审计的自身账号消息目前在 01 codec 阶段返回 400，既无 `platform_inbox_raw` 也无 `data_messages`。新门禁要求后续 01 补齐受信映射后只能落成 `unknown` 并保持 `PAUSED_OWNER`，不能误入联系人消息。03 provider 若收到 `unknown`，会保留来源且拒绝其产出本人事实；03 Owner 只读投影可安全展示引用，但当前 bridge 无法产生这一路径。02/06 尚需调用 `listUnknownOrigins` 并按 `messageId` 合并到 Owner API 的会话消息投影。

## 需要总控协调的接口提案与缺口

**G2-03-A，01 的自身消息对端映射。** `apps/bridge/bridge.mts` 调用 `ingestAuthenticatedOneBotEvent` 时未传 `resolveSelfPeer`；`onebot-codec.mts` 对 `user_id=self_id` 或 `message_sent` 要求经审计的 `selfMessagePeer`，不能信任事件自身的 `target_id` 猜测对端。请 01 在现有接口上定义受信映射来源、无法映射时的私有原始证据处理与负测；02/03 再联测 `PlatformSelfMessageUnattributed -> actor=unknown -> PAUSED_OWNER`。不建议 03 自行新增事件类型或绕开 codec。

**G2-03-B，平台撤回/编辑证据失效。** 当前 02 的 `PlatformMessageMutationObserved` 只失效计划并更新 02 generation；没有通过 03 定位原消息、失效依赖事实/分析/快照或推进 dependency epoch。D09 尚未决定撤回与编辑的正文/证据处理规则。请总控确定事件关联键与 02→03 事务接口语义后，03 增加具体 provider 方法和联测。现阶段不能把该路径报为 AC 已通过。

**G2-03-C，原始文件生命周期。** 01 的私有原始文件在数据库写入前落盘；相同平台键不同正文会拒绝数据库写入，但第二份文件可能成为无数据库引用的孤儿。D07 未定前，只记录清理需求，不声称物理媒体/原始文件/备份清除完成。

**G2-03-D，`PlatformOriginResolved` 持久化提案。** 现有 `data_messages` 只有可变 `actor`、`version` 和原始 `provenance`；没有来源更正的独立证据与旧值审计表。建议总控分配 0007/0008 之后的新迁移编号，新增只追加的来源更正记录，含 `message_id/contact_id/from_actor/to_actor/evidence_refs/old_version/new_version/event_id/resolved_at`，RLS 按 contact_id，唯一事件键做重放去重。03 provider 在 02 消费同一事务内锁定原消息，只允许 `unknown -> owner|agent` 且要求可验证的证据引用，追加更正审计、提升消息版本、失效依赖事实/分析/快照、提升 dependency epoch 并写 outbox；02 同事务失效未提交计划，保留 `OWNER_ORIGIN` 暂停直至显式恢复。不能直接覆盖原始 unknown 证据，也不能因更正自动解除暂停。需总控先明确 01 事件证据格式和公共接口，再写迁移与实现；本轮未改公共迁移。

D05 无真实历史样本，导入仍限预览/去重，不解析未知格式。D07 的媒体与原始事件文件、备份清除周期及执行机制仍待总控决定；数据库墓碑不能代替物理清除。
