# 手机电脑联动体验 0.6.0（2026-10-09，第三批）

第三批按此前确定的「简化首次关联、同步和冲突处理；显示更新时间；电脑整理相关历史供手机使用」完成。手机操作体验优先，版本 `0.6.0` / `versionCode 16`。同一批功能和验收用例写完后统一验证，发生实际失败后针对修复复验。

## 手机使用流程

1. 从「设置 → 连接电脑 / 管理资料」进入独立联动页；回复面板「更多 → 电脑资料 / 同步」直接打开当前对象。联动不再塞在长设置列表中。
2. 在电脑生成一次性配对码，手机拍摄二维码或粘贴完整配对内容。失败保留粘贴内容；过期或已使用时提示重新生成。电脑显示剩余有效时间，支持复制和重新生成。
3. 选择手机对象，按名称／平台搜索电脑联系人，同名微信和 QQ 联系人分别显示。默认「仅整理手机资料」也可关联，明确表示不读取其他电脑联系人。临时档案不参与联动。
4. 当前对象同步和全部关联对象同步分开；显示待上传的消息／资料／删除操作数量、当前同步对象和最近成功时间。计数直接使用实际同步操作计算，时间只在同步成功后更新。
5. 冲突显示关系、风格、偏好及已授权背景的可读版本，可选择电脑当前版本或待合并版本，不再展示整段原始 JSON。遇到过期选择返回 409，提示重新同步后选择；授权撤销与暂时离线分别提示。
6. 已下载背景、表达习惯和来源条数在手机展示，可打开两端聊天原文，返回联动页保留当前对象。电脑关闭、断开或解除关联后保留缓存，回复仍可使用已下载资料。

## 同步和历史整理

- 同步中新增的手机文字和偏好保留，先记录电脑已接受的版本，再继续上传新修改，避免重复把自己的更新当成冲突。尚未选择的冲突项不参与自动重传，后续刷新保留两端版本，直到本人选择。原草稿保留；只有电脑提供的实际提示上下文或接受的背景／偏好发生变化时才更新上下文版本，单纯上传确认不使草稿过期。
- 电脑编辑以开始编辑时的版本提交。后台刷新或搜索其他对象保留未保存内容；手机已有新版本时显示提示，保存进入两端比较，避免拿新版本号直接覆盖手机修改。
- 电脑按照最近可靠的对方话题查找较早相关原文，同时保留相邻发言和较近背景，按时间排列。最多64条，每条正文180字符；来源与实际显示的摘录对应。已删除、不确定、说话人未知和生成内容不进入确定背景。可选模型整理会收到近期聊天与候选原文，仅选取合法来源 ID，沿用已有共享预算；本轮没有调用真实模型。
- 保留既有对象／平台隔离、证书固定、设备授权、加密凭据、背景同意和上传范围。模型密钥、截图图片和未发送草稿不上传。新增联系人名称字段兼容旧缓存，不需要数据库迁移。
- 已删除档案不再显示在电脑联动列表，底层删除版本记录仍按已有同步逻辑保留。

- 新增手机覆盖：错误配对保留输入、搜索同名平台对象／联系人、可读冲突选择及刷新保留未选版本、离线查看及原文返回、当前对象同步隔离、离线与撤销授权状态、同步中继续修改、仅上传确认不使草稿过期。
- 电脑联动服务14项通过；现用启动目录的联动服务10项已有测试通过。电脑浏览器联动验收1项及既有工作台回归9项通过，源目录和现用启动目录的网页均构建通过。
- 未配置隔离 `TEST_DATABASE_URL`，本轮未重跑 PostgreSQL 持久层集成；本轮没有修改存储结构或数据库迁移。

初次模拟器运行发生 System UI 无响应弹窗，导致7项跨应用检查无法进入合成聊天；恢复系统界面时另有1项面板检查受到影响。初始运行的最后一项固定高度面板测试卡住，换包时运行终止；独立复验发现测试容器已处于键盘上方，却又扣除了整段键盘高度，已修正测试容器后完成复验。实际悬浮窗口的键盘／面板高度测试通过，产品未通过隐藏失败或放宽断言规避问题。保留初次与复验日志。
