# 任务 04：AI 理解、分析与回复

## 任务目标

实现多媒体理解、意图/风险分析、性格与关系分析、回复策略、1–3 个候选、事实/风格检查和结构化失败。04 输出提案，不直接发送、不修改权限/目标/事实确认状态。

## 必读与范围

依次读 PRD v1.3 §5、§7、§11–12、§14–16，[架构](../architecture.md)、[公共契约](../contracts.md)、[决策](../decisions.md)、[计划](../development-plan.md)。主责 AC06、AC25–28、AC32；协作 AC03–14、AC21、AC24、AC29–34、AC36–42。

负责 `packages/ai/{understanding,analysis,strategy,generation,checks}`、模型 gateway 与本模块评测。不要在模型工具中暴露 PlatformPort、ContactPolicy 写接口或其他联系人原始数据。

## 输入输出与依赖

实现 IntelligencePort。只接受 03 已裁剪、固定 cutoff 的 ContextSnapshot 和 02 策略投影；通过 05 请求合规 Skill 输出。所有结果符合 schema，带 model/prompt/version、证据引用、不确定性、风险、requiredFacts、confirmationReasons、skill/analysis versions、失败分类。

依赖 D06 选择真实模型，D08 提供标注，D10/D11 确定正式分析体系。此前先实现 deterministic fake 和 provider contract；草案 taxonomy 必须标 `draft-1`，不能呈现为已确认人格诊断。

## 实施要求

媒体失败不是空文本成功：动态表情需完整时间信息或明确 unsupported；关键听不清/看不清返回 MEDIA_UNCERTAIN。分析把 observation、inference、owner-confirmed fact 分开，列正反证据/替代解释；AI 自己发言不能证明对方反应之前的关系，也不能成为本人事实。

候选每个可有多条 ReplyPart；决策可等待/延迟/不回复。检查器报告事实依据、风格偏差和权限风险，但最终授权仍由 02。可自行决定 prompt 结构、provider 路由、缓存和温度；不得自行制定自动发送置信阈值、输出伪准确率、改目标/开关、跨联系人调用、保存 chain-of-thought 或调用发送。

## 验收与交付

- provider contract 覆盖结构错误、超时、限流、内容不完整、fallback；失败不会产出“可发送”空结果。
- 时间截断评测，禁止未来消息/最终摘要泄露；分别报告确认/自动模式和各媒体类型。
- AC25–28、32 覆盖少样本未知、观察/推测分离、证据/反证据、AI provenance、策略前后解释；协作安全 AC 全部结构化输出。
- 真实模型结果与 fake 测试分栏，报告 token/媒体成本、延迟和数据设置；未选择模型时不宣称质量完成。
- 交付记录包含 prompt/model 版本方式、评测集说明、测试与 AC、限制/D06/D08/D10/D11 和公共变更提案。
