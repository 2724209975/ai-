# P4-5b 独立 helper 构建与接收验收准备范围审定

总控依据本人“推进下一环节”审定本卡。源码核查补充：WeChatDb 初始化会清空 dbmap，只有旧 GetWeChatDbHandles 才发现句柄；该遍历仍依赖未验证偏移，不能为使实验内核可调用而开放任意 SQL 或直接执行遍历。故本卡准备受限接收构建与流程，语音字节探针明确不就绪，后续先复核句柄来源。

可改：`scripts/wxhelper-receive-only/`、`scripts/wxhelper-receive-only*.mts`、对应补丁、必要的离线编译测试共用工具、`docs/reports/P4-5b*`、开发计划。独立复制 `.local-wxhelper/wxhelper-src-391125` 的当前源文件（含已有本机修复和固定依赖），排除 Git 元数据；不改原树/登记 DLL。记录整个副本源文件哈希、源 HEAD/已有差异、补丁/工具链/新 DLL SHA-256/PE 架构和原 DLL 回滚指纹；构建仅 target wxhelper，不运行或打包注入器。无新增 npm/编解码依赖、无迁移/公共契约。

接收构建使用专用编译宏，固定绑定 `127.0.0.1:19188`，关闭日志、隐藏模块与外部回调；独立 DLL 旁私有配置含随机 256 位 token 和单一测试好友绑定。所有 HTTP 请求先经专用边界，WebSocket/旧 HTTP 路由不再进入 router。仅允许已鉴权 POST、无 Origin、固定 `{}` 请求的状态/登录检查/接收 hook/解除 hook，限频限总量；解除 hook 经正确 token 不受试用过期或速率限制。接收 hook 仅采集指定好友的类型计数与精确字符串消息编号，不读取正文/图片/语音缓冲，不向其他进程推送。语音数据库能力返回 false；原候选内核在完整构建中编译验证但不对运行接口开放。

构建工具只产生本机独立源码、DLL、脱敏清单与操作材料。只接收客户端/配置工具仅供本人执行（AI 测试只连接合成 HTTP 服务）；私有证据不输出 token、好友或编号。验收清单先检查版本、旧服务停止、原 DLL 可回滚，再由本人启动/注入、核对文字/图片/语音计数、解除 hook 和关闭微信。不能把新产物默认关闭/离线 HTTP 测试写成实际平台通过；不自动注入、发送或调用模型。

验收：C++ 边界负测、跨好友过滤、过期/速率/消息上限、HTTP 客户端脱敏与失败保留、全新源码副本的 x64 Release 完整 DLL 构建、指纹与回滚材料、完整 PostgreSQL/Chromium 门禁 0 fail、0 skip。下一卡为可信数据库句柄来源/偏移的离线复核，未确认前不启用 Buf 查询或 ASR。

总控追加审定 `.gitattributes` 的单文件 `-whitespace` 属性：本卡统一 diff 必须保留既有 CMake 尾部空格作为原样上下文，不能为消除 Git 空白告警而改写补丁及已登记源清单。仅作用于 `scripts/wxhelper-receive-only.patch`，不放宽源码的空白检查。
