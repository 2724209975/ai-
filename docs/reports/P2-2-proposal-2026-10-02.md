# P2-2 试用报告范围与总控审定

总控批准本卡新增 `scripts/trial-report.mts`、`packages/ai/eval/trial-report*.mts`，以及卡外 `scripts/trial-report.test.mts`、`tests/integration/postgres-trial-report.test.mts`（命令安全与真实数据库只读验证），同步交付报告和开发计划。无新增依赖/迁移，0011 不分配。

指定联系人 UUID 和带时区的半开区间，按反馈 `rating.terminalAt` 纳入终态；`presented` 不计采用率分母。原文与最终确认文字仅在内存计算字符级编辑距离，不进入返回对象；所有输出按输入顺序使用联系人序号和候选序号，禁止输出内部 ID、身份、正文、任意来源字符串或错误细节。采用率分母是所有区间终态，并列列出重新生成和失效。

模型日志目前没有 planId/contextSnapshotId/contactId，P1 工具已标为 time-window-only。本卡不以时间接近自动归属，也不把全进程调用费用归到选中联系人。允许读取显式 planId 关联的测量 JSONL（供合成验证或未来采集），每条候选显示 token/时延/费率估算与覆盖率；现有未关联日志仅报告“区间不可归属行数”，指标为 null。一次调用生成多个候选，费用属于整个方案生成，不重复分摊为各替代候选费用。可选费率由本人显式输入，不硬编码供应商价格，不调用真实模型。

现有暂停状态和 epoch 是当前快照，缺少完整历史；控制命令 hash 不能证明暂停次数，失效方案数不能当暂停次数。报告将区间暂停次数设为 null，标明历史缺失，同时展示当前暂停原因数量分布（固定原因字典，未知归为 unknown）。区间估算/空值不作为已完成质量验收。补齐模型关联及完整暂停事件采集需要后续独立卡，不能在本卡偷改 02/01 行为。

CLI 只读本机数据库，单次一致性只读事务、逐联系人 RLS、参数化 SQL、窗口与行数上限；stdout 仅去标识化 JSON 或可直接粘贴的 Markdown，失败输出固定错误。真实数据库测试验证只读事务和联系人筛选，离线测试覆盖计算/缺失/重复输入/输出泄漏。全部使用合成数据。
