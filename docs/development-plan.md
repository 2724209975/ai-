## 1. 总体路线

核心判断：发送安全（租约、账本、未知结果暂停、隔离）已经做得很扎实，但**回复好不好用从未验证**。P2/P3 保留真实运行门槛；本人于 2026-10-02 决定先按默认顺序开发 P4，随后继续真实试用与验证。功能开发全部在本人电脑上完成，最后再决定部署到哪里。

```text
P0 工程底座 ──┐
              ├─> P1 真实闭环验收 ─> P4 扩展功能开发 ─> P2 本机试用期（1–2 周）─> P3 小范围自动模式 ─> P5 常在线部署 ─> P6 收尾
P2 开发任务 ──┘   （P2 的开发任务可与 P0/P1 并行，试用本身要等 P1 通过）
```

P0–P4 全部在本人电脑上运行：电脑开着才收信、出候选和发送；关机或休眠时什么都不做，重启后按现有机制「启动即暂停」，不会补发。
