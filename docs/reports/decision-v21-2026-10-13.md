## 已交付

- 兼容 2.0 的严格 2.1 决策协议；L1–L4、意图/情绪、歧义、风险标签、来源证据校验。
- Provider 配置化主/备用分类与独立深度分析，支持原兼容协议及原生 Responses/Messages；推荐 ID 仅出现在配置示例，业务代码没有型号判断。
- L1/L2 使用原生成模型与三候选/个人风格机制；L3 追加有来源的完整记忆上下文后分析，再使用原普通生成模型；L4 进入现有人工补充通道并显示审核提示，不产生候选或发送任务。
- 分类不调用查询 Embedding，复用近期对话、短关系摘要、边界及少量关键词相关记忆。L3 可按既有授权调用可选语义检索。
- Shadow 在旧流程完成后后台观察，单独记账与保存；不会替换旧候选、修改审批版本或暂停联系人。明确拒绝场景也可记录观察结果。正常停止等待在途 Shadow 工作。
- 管理台模式/模型/置信度/联系人/灰度比例/实验标识设置、等级/升级/分析显示、按等级与观察模式统计。默认 off，示例 shadow，所有 v2 候选仍人工审批。
- 新迁移 0018，复用旧决策和用量字段；新增 Shadow JSONB、analysis 调用类型和来源变化清理触发器。删除/纠正记忆后，新分析派生正文清除，旧快照的审批被现有门禁阻断。

## 回放指标与限制

24 个夹具覆盖普通闲聊、暧昧、委屈/吃醋/误解、模糊潜台词、拒绝/分手、隐私/金钱/现实承诺，保留历史与截止后数据排除。该合成离线集上复杂情绪漏判率 0、普通消息误升级率 0、JSON/结构错误 0、外部调用费用 0、平台调用 0；延迟为本地夹具耗时，不能用于推算真实 API 延迟。实际长期记忆召回和证据删除在独立 PostgreSQL 测试中验证。

用户确认暂时没有真实脱敏历史数据。因此本轮未进行真实历史效果评估，也未向指定的 GPT/Claude 模型发起收费请求。三个原生/兼容协议的 HTTP 格式与计量使用注入响应验证；真实账户可用性、语义漏判率、费用与 API P95 仍需实测。该项为 Shadow/灰度启用前的待验收项，不宣称合成测试证明自然度或模型质量。

回滚首先将 decisionEngineV21.mode 设为 off 并保存，随后新任务沿用旧引擎；若回退旧源码，先删除整个可选 decisionEngineV21 配置字段。保留新增兼容列、模型账本与迁移，不删数据库数据，不改已提交/未知发送结果，不自动恢复被暂停联系人。启用仍需先跑 Shadow，再按联系人白名单和稳定实验分组逐步扩大 Active 比例。
