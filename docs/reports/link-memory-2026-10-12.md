# 联动长期记忆核对（2026-10-12）

本批延续功能优先、费用新功能延后的要求，补齐电脑联动页的记忆查看与证据核对。已经部署到当前 QQ 候选工作台；手机协议与安装包不变。

## 功能

- 按关键词、记忆类型和状态筛选。显示有效、待确认、过期、被替代、尚未生效、超出保留期限、记忆停用、所属对象不匹配或聊天来源失效等具体原因。计算沿用现有有效期、来源性质、证据、保留期及对象范围，未修改实际生成策略。
- 每条记忆展示有效期、锁定状态与聊天来源数量；本人直接确认、没有绑定原文的内容明确标注。有效表示可以参与检索，不代表每轮一定采用。
- 「查看聊天来源」读取同一所有者、联系人、会话和账号下的原文，展示手机/电脑来源、说话人、时间和引用版本。截图日期未知时不推断日期。
- 证据版本过时、已删除或不可取得时不显示旧版本原文或替换后的内容。资料刷新改变记忆记录版本时清除旧来源视图；重新请求前也清除旧结果，读取失败保留错误说明。
- 本页只读。确认、纠正、过期或删除记忆继续使用原记忆中心，未新增记忆或改变真人授权范围。

复用 `DesktopLinkCollector` 与 `MemoryRepository` 读取证据，添加所有者 GET 接口 `/api/v1/mobile-link/evidence?groupId=...&recordId=...`；证据引用从当前数据库记忆取得，不信任客户端传入的引用。没有数据库迁移，没有模型请求，也没有平台发送。
