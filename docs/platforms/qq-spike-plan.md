本页把 G2 入口的账号、知情联系人与常在线宿主条件及工程缺口分开列出。公开资料只作 spike 输入，不构成能力验证。

**来源专项增量**：本人从原 QQ 客户端手发的首个 `message_sent` 真实样本已由只接收桥接捕获，`target_id` 与既有知情好友入站对端在私有环境中一致；系统仍按 `unmapped_self` 暂停账号。随后经逐条授权，同一好友收到一次系统文字发送，平台回显的消息 ID、账号、对端和原文均与发送账本吻合；02 仍按 `unmapped_self` 暂停隔离库会话。`owner_message_signal` 保持 unknown，送达未获证明。见 [专项记录](../reports/qq-self-origin-2026-09-24.md)。

## 1. 为什么先做 QQ

01 的 QQ OneBot 协议层已有 95 项离线测试（事件解码、媒体指针、自身来源分类、恢复评估、发送执行器、出站传输）；微信没有任何已验证候选，个人微信现有好友会话也没有可确认的官方路径。先验 QQ 能以最低新增代码换到第一份真实证据；这不代表微信被放弃，两个平台的 AC23 仍需分别实测。

## 3. 01 侧实现现状与阻塞

已有（离线、无真实连接）：私聊事件解码、wire→公共事件归一化、传输层鉴权入口、媒体指针采集与私有存储接口、自身来源分类端口、恢复评估、发送执行器、OneBot 出站 HTTP 传输、95 项离线测试。

2026-09-24 已补齐的三项，见 [A16](../decisions.md)：

1. **入口进程**：`apps/bridge` 组合根已落盘，接「事件推送 → 传输鉴权 → 解码 → 原始字节私密落盘与 inbox/outbox 同事务 → 02 消费」。
2. **原子接纳的 PostgreSQL 实现**：`packages/infrastructure/postgres/reception.mts` 落盘，含私有原始事件文件存储（0700 目录 / 0600 文件 / 原子写）。
3. **出站接线**：02 的平台依赖改为结构化端口 `DispatchPlatform`，QQ 侧由 `packages/platform/qq/napcat-bridge.mts` 提供；发送仍只在 02 的 `withDispatchLease` 内发生。

当前缺口：自身消息的经审核 peer mapper 与人工/系统回显区分；媒体原件下载与 03 私有存储；已批准表情素材读取；真实历史连续覆盖、发送核对与独立在线宿主。`apps/bridge` 默认只接收，只有显式 `QQ_ENABLE_OUTBOUND=1` 才配置真实发送传输与 worker。混合或空白内容归为 `unsupported`。名单外只存最小发现元数据，无法映射的自身消息私密留证并在同一事务暂停账号；待处理 outbox 有启动/常驻 pump。以上机制已有隔离 PostgreSQL + 假 OneBot 负测，**不能据此推断真实平台会补齐断线消息或长期稳定**。

## 5. 执行顺序（每步产出可复验证据）

0. 宿主只读核查（沿用 aliyun-readiness.md 的命令），固定 NapCat 版本与镜像摘要，保存许可文本；不改现有业务、不开放公网。
1. 沙箱账号登录：验证登录稳定性、是否依赖扫码或手机在线、失败与恢复方式。
2. **只接收不发**：跑入站能力矩阵（文字、图片、语音、静态表情、动态表情、引用、撤回、自身消息），保存脱敏原始事件样本，逐项标注 `documented`、`tested`、`unsupported` 或 `unknown`。
3. 媒体验证：原图、原语音、动态完整性，`get_image` 与 `get_record` 的路径语义与跨主机可读性，URL/token 失效期。
4. 本人发言识别：手机手发、桥接回显、系统消息三类对照，验证 `self-origin` 分类；无法区分则记录缺口并禁用自动模式。
5. **受控出站**：在 [verification.md](verification.md) 的批准清单内，经 02 租约发送文字与已批准表情，记录回执层级与 `message_id` 关联。
6. 故障注入：重复、乱序、断网、提交中断、核心与桥接分别重启、重登；验证 `RESULT_UNKNOWN` 与 reconcile，不重发。
7. 关机验证：关本人电脑，确认接收、判断、生成、发送持续，如实记录对手机、扫码或常在线设备的依赖。
8. 产出 `docs/reports/platform-qq-YYYY-MM-DD.md`，结论只能是 `GO_CONFIRM_ONLY`、`GO_AUTO`、`CONDITIONAL` 或 `NO_GO`；模拟或公开文档结果不得计入。
