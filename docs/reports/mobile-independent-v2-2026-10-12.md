# 手机独立生成与电脑记忆同步：0.7.0 交付

按本人要求完成源码实现与安装包构建。手机辅助生成三条候选，用户编辑、复制后自行粘贴发送；电脑和手机只同步资料。手机起草直接调用本机配置的模型，电脑关闭后仍能使用最近同步的资料生成。

## 已实现

1. 手机截图和主动读取的聊天文字按 `import` 历史模式进入电脑 v2 数据层，保留说话人、来源、修订与不确定信息。重复同步幂等；纠正/删除使旧证据及依赖记忆失效。历史同步没有平台实时入站、自动回复任务或发送副作用。未发送草稿不上传，“我已发送”记录仍是人工确认，不冒充平台回执。
2. 电脑完整 `memory_v2/context_v2` 数据下载到手机：所有者、账号、联系人、会话、记忆 ID/版本、类型、主体、内容、证据性质与来源版本、状态、有效期、锁定信息、重要性与置信度，以及确认关系和表达配置。手机按当前话题检索，排除过期、待确认、删除、被替代和来源失效的记忆。账号/对象隔离；手机不能伪造或删除电脑记忆。
3. 手机实际生成入口改为：识别聊天 → 本地上下文 → 低成本决策 → 按风险选择生成模型 → 三候选 → 本地风格与质量检查。决策采用桌面相同的 13 字段契约；Android 使用本地实现，不宣称所有规则或结果与桌面逐字相同。文字通常两次调用；首次截图通常三次；识别后失败重试或改写不重复识图。wait/skip/ask_user 不调用生成模型。
4. 复杂/敏感对话使用配置的高档模型。高档尚未配置时明确提示使用低成本模型核对；高档调用失败后不静默降档或重试。模型配置变化、来信或同步资料变化会使旧结果失效；手工草稿保留。复制时再次检查编辑后的内容与记忆有效期。
5. 每日调用数与预估 token 上限在请求前持久记录，失败/重启不返还；图片估算单独计入，避免把 base64 当文字计费。该计量是保守用量控制，不是实际费用账单。手机模型密钥加密保存在本机，不同步；两端费用账本未合并。
6. 截图中的本人发言仅在被明确标为表达样例后参与电脑风格学习。已知 AI 候选、不确定说话人与未标记截图表达被排除。电脑原有真实本人发言及已送达的编辑反馈沿用原规则。

复用原有截图获取、原文纠正、对象档案、本地存储、三候选面板、配对、HTTPS 证书绑定、增量游标与冲突处理。新增逻辑集中在 Android `MobilePipelineV2/ModelClient/AssistantController/MobileUsageStore` 和电脑 `packages/link/v2-data`；没有推倒重写。

## 当前运行与使用

- 安装包：`output/android/reply-assistant-0.7.0-debug.apk`，版本代码 18，可覆盖旧版保留档案与配置。APK、JVM、Lint、设备测试包编译通过。本轮没有真机安装、设备 UI 执行或真实模型质量测试。
- 当前电脑工作台：`http://127.0.0.1:55135/#link`，同 Wi-Fi 使用 `http://192.168.31.17:55135/#link`。同步服务：`https://192.168.31.17:8791`，范围仅为已授权的 QQ 好友冬冬（3786341198）和🐑（1524209299）。
- 安装后在手机设置填写截图识别模型；展开低成本配置填写决策/日常回复模型；另填高档模型接口、名称与密钥，再保存。旧文字配置保留；未配置文字 Key 时沿用截图模型处理纯文字。高档由本人配置，本轮没有替本人选择真实高档模型。
- 电脑「手机联动」生成配对码，手机「连接电脑」扫码或粘贴，然后明确关联同一人的电脑联系人。旧日常库的设备凭据不能直接用于此次独立试用库，需要重新配对；原有手机资料保留。
- 手机截图识别后保存的原文自动排队同步。电脑已确认的长期记忆在下一次成功同步下载；手机「电脑长期记忆」可查看有效条目。断开电脑时资料更新等待重连，手机仍可通过互联网调用自己的模型。
- 本机按当前时间排除已过期的缓存记忆。电脑断开后才发生的新修改/删除，必须重新同步后才能获知。手机没有网络时保留聊天、截图和草稿，等待重试。

当前 QQ 试用没有发送器或审批发送入口；真实自动发送未启用。重启部署保留原费用账本，未提高上限、清零用量或扩大联系人范围。本轮未发起收费模型测试。
