# 手机与电脑使用、备份和升级指南

当前安装包：Android 0.8.0，Android 14 及以上；已覆盖安装到本人手机。手机每次生成三条候选，编辑、复制后由本人到原聊天发送。电脑可承担资料整理和复杂管理；当前 QQ 试用仍只生成候选。

## 首次配置

1. 安装 `output/android/reply-assistant-0.8.0-debug.apk`。旧版请直接覆盖安装，不卸载、不清除应用数据。
2. 在手机「设置」填写截图识别模型接口、名称、密钥。低成本模型用于决策和日常回复；未单独配置低成本密钥时沿用截图模型。高档模型可稍后自行填写，复杂回复未配置高档时会提示核对。
3. 设置页显示各阶段模型和配置问题。接口必须使用 HTTPS，不能把密钥放在地址里。配置检查不访问模型服务、不收费，不代表接口已经验证可用。
4. 按服务商的实际计价填写三个模型的输入、输出价格，单位是元/百万 token。输入价格建议按不使用缓存优惠的价格填写。价格未填写时仍统计次数和用量；启用手机金额上限或领取电脑额度后，未填写本轮价格会阻止请求。
5. 每日调用和用量按北京时间计算。每日手机金额上限为 0 时不额外限制金额，但领取的电脑额度始终生效；修改价格或限额不会消除已预留费用。

## 连接电脑与费用分配

1. 两端使用同一 Wi-Fi。电脑工作台「手机联动」生成配对码，手机「设置 → 连接电脑」扫码或粘贴。当前 QQ 候选工作台和旧日常库是不同入口，凭据不能混用。
2. 手机选档案并关联同一人的电脑联系人。模型密钥、截图原图和未发送草稿不参与资料同步。
3. QQ 候选入口及更新后的普通电脑/微信入口在「手机联动 → 两端费用与额度」显示当前账本上限、电脑记账、手机上报费用和剩余金额。在此输入手机**累计额度**，分配后在手机同步领取；不会默认分配，也不会提高原总上限。普通多平台入口需配置同一份账本，见[共用费用指南](unified-budget.md)。
4. 分给手机的额度立即从电脑可用额度扣除。手机离线调用自己的模型，并在请求前持久预留费用；重连后只上传费用/调用/token 合计，不上传密钥、调用文本或模型返回。
5. 手机额度只能增加，不能在手机离线时回收。撤销、断开、重启、备份恢复不返还费用。手机页面和电脑汇总显示最近成功同步快照，断网期间电脑不能知道手机刚产生的用量。
6. 普通 Core、QQ、微信和双平台联动已接入共用文件账本，原 QQ 候选试用专用账本保留。旧电脑服务需统一更新后生效；没有配置费用时显示 0 元，不自动增加授权金额。已领取额度的手机不能通过切换旧入口解除限制。不同账本不自动迁移离线额度或重复授予同一份预算。

费用是按填写价格和输入/输出上界做的保守预留，不是服务商账单。网络失败、取消、缺少 usage 和重启保留预留；返回 token 超出预留范围会阻止后续请求，须核对接口计量。图片按每张额外 8192 token 预留，未知模型的真实图片计价仍需核对。此前授权总预算继续有效，不得以升级或分配额度为由清零、增加上限。

## 查看生成和同步情况

- 手机 0.8.0 同步一次后，电脑的手机原文提供「纠正原文」，可修改文字、说话人和不确定标记；来源和时间保留。手机接收修订后更新本机原文，依赖旧内容的记忆和候选失效，手工草稿保留。两端同时改同一条记录会显示冲突，选择后再同步，不静默覆盖。
- 可靠且非助手生成的原文提供「从原文整理记忆」，选择类型、所属人、内容及到期时间，确认后保留对应证据版本并同步到手机。不确定内容先纠正；截图时间未知仍保持未知。
- 手机按对象保存生成阶段与重写要求。取消、网络失败和应用中断保留原文与手工稿，提供「重试上次生成」；已识别的截图文字复用，高档失败不会静默降档。正在执行的请求不会在重启后自动重发。
- 展开电脑「同步给手机的长期记忆」，可按关键词、类型和有效/待确认/暂不使用筛选。每条标明过期、未生效、超出保留期限、来源失效或记忆停用等具体原因；有效只代表可参与检索，是否用于本轮还取决于聊天话题。
- 有聊天证据的记忆可点击「查看聊天来源」，核对原文、说话人、手机/电脑来源与引用版本；截图原文没有时间时保留“时间未标注”。已修改、已删除或无法取得的来源不展示成旧版本证据。本人直接确认且没有绑定原文的内容会明确标注。确认、纠正或停用仍在记忆中心完成，本页只读查看。
- 电脑「手机联动」显示当前关联的具体电脑联系人，搜索联系人名称也能找到手机对象。展开「手机可用的历史资料与表达习惯」查看原文，支持关键词、手机/电脑来源、说话人组合筛选及每页 50 条翻页；未标注时间的原文不会猜测日期。数量只代表已同步记录，不能据此认定 QQ 历史完整。
- 「手机接收确认」来自手机下次请求带回的游标，说明此前的响应已收到并解析，不等于确认已经写入手机磁盘。电脑发出响应不会立即算作收到；旧资料没有此记录时等待手机下次同步。显示确认时间、已确认资料版本和待接收数量；手机恢复较旧缓存时会明确提示。超过两分钟未请求只提示最近未同步，不断言设备离线。
- 已有 QQ 候选试用在 QQ 离线时仍可启动工作台、管理资料和同步手机；恢复 QQ 接收前自动重新核对登录账号与限定联系人。首次创建试用仍须 QQ 在线完成核对。电脑服务本身关闭或手机无法访问网络时仍需等待重连。
- 手机回复面板展开更多信息，可查看本轮模型、选择原因、近期聊天数量、采用的记忆和聊天依据。高档失败不静默改用低成本模型。
- 电脑回复任务展开「本轮生成说明」可查看模型选择和质量结果；聊天设置中的上下文检查可查看聊天与记忆选取。
- 手机联动显示待同步修改、资料更新时间和两端冲突。超过一天未更新会提醒；电脑离线后才发生的修改/删除，手机要重新同步才能知道。
- 重新关联后保留的旧记录会显示「旧关联」「已解除关联，保留旧资料」，当前连接单独显示；旧记录的保留不代表仍在同步。2026-10-12 已修复数据库字段顺序导致的重复版本增长，重复同步不会把同一份原文、上下文或风格当成新内容，详见[同步稳定性记录](reports/sync-stability-2026-10-12.md)。
- 连接失败先确认电脑服务已启动且两端在同一网络。地址/证书变化或授权被撤销时重新配对。失败保留本地原文、缓存和手工草稿。

## 加密备份与恢复

1. 手机「设置 → 加密备份与恢复」输入至少八位密码，点击导出，选择自己的保存位置。备份以 PBKDF2-HMAC-SHA256（210000 次）与 AES-256-GCM 加密，文件扩展名 `.rab`。
2. 包含手机档案、聊天原文、手工草稿、回复偏好和已下载资料；不包含截图原图、模型密钥、通知会话绑定、配对 token、费用额度或本机费用账本。没有当前截图处理会话的图片恢复。
3. 恢复时先输入原密码，选择文件，查看日期、档案名称、记录/草稿数量和将跳过的已有档案。确认后只新增缺少的档案，不覆盖同 ID 的当前档案。可选择合并全局偏好。
4. 恢复后模型配置与本机用量保留；草稿需核对当前上下文，电脑关联需要重新建立。重复恢复不会复制同 ID 档案。密码错误、文件损坏或未知版本不会改动现有资料。密码丢失无法找回。
5. 更换手机需要重新填写模型、配对并领取新设备额度。旧设备可能仍能离线花费，不能仅因换机就返还旧额度。旧手机用量不通过聊天备份迁移，电脑保留旧设备上报账本和累计分配。

## 升级与回退

- 项目根目录「启动项目」「停止项目」「检查启动配置」「更新项目」统一使用当前源码和已授权 QQ 候选实例。检查入口显示运行状态与版本；更新先构建网页，成功后管理式重启，保存旧网页入口，不重建私有配置或费用账本。命令入口为 `node scripts/project-control.mts start|stop|status|restart|update`。电脑页显示实际网页版本与手机推荐版本，服务端版本不同会提醒刷新。
1. 升级前导出手机加密备份；电脑沿用现有 PostgreSQL/预发布备份流程。涉及 QQ 试用时，同时保留私有运行目录的 `manifest.json`、`calls.jsonl` 和数据库 `mobile_link_state`，两份费用记录不能分别回滚。
2. 覆盖安装同签名新版；手机设置和档案数据库兼容新增字段，旧每日调用计数迁入新用量记录。不得卸载后重装来回补额度。
3. 电脑使用当前源码构建网页和管理式重启，仍沿用原试用目录、原模型私有配置和原预算，不另建更大额度的试用。2026-10-12 已备份并恢复新版 QQ 候选服务，仍关闭真实发送；旧双平台目录仅更新模型费用与发送隔离修正，没有整体迁移或启动。安装 APK 不会替电脑部署，详见[此次部署记录](reports/deployment-2026-10-12.md)。
4. 若新版有问题，先保留聊天和费用账本，停止新增模型调用，修复后更新。不要直接恢复旧费用文件/数据库快照，也不要强制降级 APK 覆盖新数据；电脑回退依照现有预发布指南进行隔离恢复与对账。
