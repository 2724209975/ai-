# QQ 候选试用的高低模型搭配

当前电脑 QQ v2 路径已支持两档真实模型。低成本模型继续使用既有 DeepSeek Flash 接口和密钥；高档模型由本人填写，使用独立 HTTPS Chat Completions 兼容接口和密钥。没有填写高档配置时沿用原模型，不声称高低两档已启用。Android 独立 App 本轮不变。

| 环节 | 使用方式 |
| --- | --- |
| 回复决策 | 低成本模型 |
| 普通问候、分享日常等低/中风险回复 | 低成本模型 |
| 情绪冲突、敏感承诺等高风险且需要回复的场景 | 高档模型 |
| 等待、跳过、需要补充关键事实 | 不调用生成模型 |
| QQ 图片理解 | 现有支持图片的低成本模型；解释进入文字上下文 |
| 结构、表达和质量检查 | 本地程序，不额外调用模型 |

每轮需要回复时通常两次调用：低成本决策 + 选定档位生成三候选。不会先调用低成本生成再无条件调用高档生成。当前不配置自动备用模型，避免额外调用掩盖错误。具体高档模型是否改善聊天质量需配置后对比验证，价格高不能直接证明效果好。

## 在工作台填写

进入当前 QQ 工作台，选择任一试用好友，打开“聊天设置”中的“高档模型配置”。这里的高档模型配置供两位试用好友共用。

1. 填写精确模型 ID、HTTPS 接口基础地址、API 密钥、人民币输入/输出价格、官方价格说明地址及核对日期。
2. 点击“保存高档模型配置”。这一步仅保存私有草稿，不调用模型、不产生费用、不改变运行中的模型。
3. 核对页面上的已保存模型，点击“启用已保存配置”。候选服务短暂重启，页面确认“已启用”后，新任务按两档路由。

未保存的表单修改会禁止启用。页面不会回显已保存密钥；再次保存时，密钥留空会保留原密钥。密钥只写入本机私有试用目录，不写入浏览器本地存储、仓库或报告。启用后的状态只代表服务已加载配置，接口、密钥和实际生成效果仍需真实调用验证。

草稿文件与运行配置快照分开存放。修改草稿后，即使服务重启也不会自动加载新草稿，必须再次点击启用。启用保留既有预算、已消耗费用、联系人范围和本人暂停状态；真实自动发送始终关闭。

供应商标识、模型版本、缓存价格、数据处理地区、保留政策和可选思考参数可在“供应商与高级选项”中填写。

## 使用私有文件填写

使用 `deploy/qq-quality-model.example.json` 作为模板，保存为当前私有试用目录中的 `quality-model.json`。密钥不要填入仓库模板、报告或聊天。

- `providerId`：模型供应商标识。
- `modelId`：供应商要求的精确模型 ID；`modelVersion` 记录所选版本。
- `baseUrl`：基础地址，例如 `https://供应商/v1/`；程序追加 `chat/completions`，不要填完整请求路径。必须 HTTPS，禁止重定向。
- `apiKey`：该供应商密钥。
- `dataRegion`、`retentionPolicy`：供应商处理地区与保留政策；未核实保留政策可保留 `provider-default-unverified`，不要虚构承诺。
- `price`：人民币计费的每百万 token 价格。输入/输出填写正数，缓存输入可填 0；采用最高适用输入和输出价格并填写官方来源、价格日期，不确定不能启用。当前试用不自动换算美元价格。
- `thinking`：可选；只有供应商明确支持 `thinking.type` 时才添加 `"disabled"` 或 `"enabled"`。默认不向其他供应商注入此专有参数。

价格占位和密钥占位会被拒绝，配置命令本身不调用模型、不花钱。

## 验证配置与启用

项目目录下运行：

```powershell
$qqTieredPointer = Get-Content -LiteralPath '.local-prerelease/qq-candidate-current.json' -Raw | ConvertFrom-Json
$qqQualityFile = Join-Path $qqTieredPointer.root 'quality-model.json'
node scripts/qq-trial-control.mts configure-quality $qqTieredPointer.manifest $qqQualityFile
# 只有上一步成功后才执行重启；当前会话仍只生成候选。
if ($LASTEXITCODE -eq 0) { node scripts/qq-trial-control.mts restart $qqTieredPointer.manifest }
```

保存配置不会单独重启或解除本人暂停。重启应用新配置，旧待处理候选会按模型配置变化失效，新的来信按两档生成；模型设置页面显示决策/经济/高质量所选模型及用量。替换模型注册、价格或思考模式也会使旧任务失效。

两档模型和图片理解共用原试用额度与调用次数，不重置此前消耗。每次请求按对应模型的保守价格预留并结算，价格随账本记录；旧单模型账本仍按原价格恢复。费用不明时停止新增调用，重启不会退回或遗忘已消耗额度。真实自动发送仍关闭。
