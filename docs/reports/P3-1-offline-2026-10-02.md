## 已交付的离线工具

运行 `node scripts/wechat-receipt-evidence.mts <本机私有清单.json>`。工具仅读取明确列出的原始 `.bin` 样本，不请求网络、不查数据库、不写文件、不扫描整个聊天目录。先由本人安排并授权采样，之后在私有目录填写清单：

```json
{
  "schemaVersion": 1,
  "ownerAuthorized": true,
  "declaredSource": "system",
  "selfRef": "wxid_synthetic_self",
  "peerRef": "wxid_synthetic_peer",
  "expectedText": "P3 synthetic marker",
  "startAt": "2026-10-02T10:00:00Z",
  "endAt": "2026-10-02T10:00:30Z",
  "baselineFiles": ["before.bin"],
  "observedFiles": ["after.bin"]
}
```

这里都是合成示例，实际身份与正文只能保存在本人私有清单。路径相对清单所在目录，也可显式指定绝对路径；工具拒绝直接指向符号链接的输入、超大文件、未知清单字段及缺少授权声明。单份清单最大 64 KiB，单样本 1 MiB、累计 16 MiB，每组最多 500 样本，窗口最多 10 分钟。`declaredSource` 只接受 system/owner/control，它是本人声明，工具始终输出 sourceDeclarationVerified=false。

算法复用现有解码器，保留大整数消息 ID；先排除基线 ID，再检查自身 → 指定好友、精确文字、限定平台时间窗口。重复 ID 去重；同一 ID 的关键内容/方向/时间冲突标 CONFLICTING_IDS；多个新匹配 ID 标 AMBIGUOUS；任一输入无效标 INCOMPLETE_INPUT；没有候选标 NO_MATCH；只有一个标 UNIQUE_OBSERVATION。展示字段或 signature 包含标记不会构成匹配依据。

输出只含序号之外的固定状态与计数，不含正文、身份、ID、哈希或路径。**UNIQUE_OBSERVATION 仅表示出现一个新的精确自身消息观察**；本人也可能发相同文字，时钟有偏差、时间戳只有秒精度、采集范围也可能不完整。因此所有结果始终 origin=unknown、receiptLevel=unknown、canResolveUnknownSend=false、canEnableAuto=false。不能拿该输出解除未知发送或抑制本人接管。
