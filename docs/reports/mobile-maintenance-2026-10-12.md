# 手机与电脑辅助功能补齐：Android 0.7.1

按本人「测试后面再做，把这些都补完」要求完成源码与安装包交付。五项范围：费用管理、加密备份恢复、模型配置体验、生成/同步说明、交付升级指南。没有真机安装、收费模型调用或真实好友试用；没有启用真实自动发送或提高费用限额。

## 实现

1. **费用与调用记录**：复用手机持久存储及电脑 QQ 试用账本。手机所有 ModelClient 请求（含军师）在网络发出前预留次数、输入字节上界/图片 allowance、输出上限和按角色配置的价格，保存用途、模型、时间、响应用量和状态。未配置价格明确记为未定价；开启每日金额限制或领取统一额度后必须有本轮价格。失败/取消/重启不返还预留，超出预留 token 会阻止后续调用。北京时间每日次数/用量限制沿用，旧版计数迁移不回补。
2. **QQ 两端预算分配**：在已有 owner-scoped `mobile_link_state` JSON 中增加账本 ID 和各设备累计分配/消费合计，无新增迁移。授权 Owner + CSRF 才能分配，设备只能读取/报告自己数据。电脑 PaidReplayBudget 在原调用准入中扣除手机全部累计分配，保留原历史账本与总上限；手机领取后可离线使用，重连单调上报，重复上报幂等，不能缩减额度、倒退费用或越权修改分配。断开或撤销不回收离线资金。电脑聊天页剩余金额也扣除手机分配。
3. **备份与恢复**：PBKDF2-HMAC-SHA256/210000 次 + AES-256-GCM 的 `.rab` 文件，使用 Android 系统文件选择器。聊天档案、原文、草稿、偏好及已下载资料可备份；截图原图、模型 Key、token、通知绑定、费用账本/额度不导出。恢复前显示日期、档案和数量；确认后只新增不存在的档案，可合并全局偏好，同 ID 保留当前版本，恢复的关联停用并需要重新配对/关联。坏文件/密码错误不改现有数据，重复恢复不重复档案，旧草稿保持需要核对。
4. **配置与过程说明**：设置页显示识图、低成本、高档模型阶段分工、未配置状态和本机格式问题；金额和价格可分别配置。无需连接模型的检查不会收费，不冒充可达性验证。手机更多信息显示实际生成模型、路由原因、聊天数量、记忆内容与聊天证据；电脑回复任务将路由原因解释为普通文字，保留详细诊断。联动页补资料超过一天未更新的提醒和连接异常恢复指引，原有待同步/冲突界面复用。
5. **交付文档**：新增 `docs/mobile-setup-and-upgrade.md`，涵盖安装、配置、配对、额度、备份、恢复、覆盖升级与回退限制。更新 README、当前需求、独立生成方案及开发计划；历史文档的自动填写描述以当前辅助定位为准。

## 安装包与实际边界

- `output/android/reply-assistant-0.7.1-debug.apk`，versionCode 19，可覆盖同签名旧版。SHA-256：`2546EE07C1B1590829858E7B967B6B1208F6140C706ADD633F47AB190BFCA1BF`。
- 本轮没有重启真实 QQ 实例；电脑费用接口新增代码需要后续按现有私有试用目录部署/管理式重启。没有默认给手机分配额度、清零原试用账本或重置联系人状态。
- **统一预算当前支持 QQ 候选试用入口**。普通电脑入口未接入此账本时会明确显示分别计量。已领取额度的手机不能靠切换旧入口解除限制，不同账本的离线额度不自动迁移。
- 手机离线费用在电脑页面是最近上报快照；分配的资金始终被电脑保留。费用按手填价格保守预留，不是供应商账单；未知模型图片计价和实际费用仍需核对。
- 真机文件选择器、覆盖安装、后台限制、真实模型质量和计量按本人要求留待后面验证。当前源码和安装包交付不代表这些现场项目已通过。
- 真实自动发送继续关闭。手机无自动填写或消息提交执行路径。
