  1. 令牌过滤: 账号 a4151 属于管理员组，但进程以普通用户令牌运行，
     takeown / icacls / C:\Windows\** 删除全部被拒绝，必须显式提权。

  2. 编码陷阱: PowerShell 5.1 读取"无 BOM 的 UTF-8" .ps1 时按 ANSI/GBK

     这正是更新缓存"错误 0 个却一个文件都没删"的原因。
     已改为 Get-ChildItem 枚举后逐个删除。

  4. 反效果提醒: 清空 SoftwareDistribution 后重启 wuauserv，
     Windows 会立即重新扫描/下载更新。若希望真正保住空间，
     应在清理后暂停更新，或直接关闭 Windows Update 服务再清。
