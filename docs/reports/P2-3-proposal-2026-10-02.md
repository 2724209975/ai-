# P2-3 总控审定与迁移分配

本卡需把已有 04 prompt 版本穿过 02 持久化边界，不修改任何发送/权限/风险判定。总控批准卡外范围：`packages/orchestration/conversations/engine.mts` 的可选元数据字段，`confirmed-service.mts` 的方案 INSERT 元数据，`db/migrations/0011_plan_generation_versions.sql`，`apps/core/main.mts` 与 `apps/bridge/wechat-main.mts` 的模型日志关联字段，真实数据库集成测试、开发计划及本报告/交付报告。0011 分配给本卡，新增 nullable `generator_version`、`prompt_version`，旧记录不猜测回填。

模型 measurement 增加快照 ID 和调用 UUID，运行日志保持只含版本与测量；日志通过同联系人方案的快照 ID 明确关联，试用报告可按已登记版本分组，未知版本统一 unknown，禁止任意标签泄漏。日志不记录联系人身份或正文。

候选提示词注册为固定版本，保持当前默认模板不变，另加离线比较版本。回放仅接受本人授权、去标识化的严格文本样本白名单；不接受摘要、分析、原始平台事件或任意额外字段。时间截断同时覆盖消息、事实确认/有效时间和事实证据，策略必须声明在截止前有效。所有消息标为 replay，工具没有数据库/平台/发送端口。

默认 fake；真实 DeepSeek 需要命令显式 provider/allow-paid、样本额外外发授权及显式单次运行调用/token预算，受输出长度和调用预算约束。本次验证只能用 fake 或 fixture HTTP，不调用付费服务。缺失用量按预算耗尽处理，禁止忽略；供应商一次调用可能超过剩余 token 预算，需明确说明非账单硬上限。

stdout 仅序号、固定版本与数值/固定状态。候选正文供盲评仅在本人显式指定的本机私有文件输出（默认不输出正文），不提交真实样本。输出不含未来回复或未来事实。泄漏负测、授权/预算拒绝测试、真实 PG 元数据与报告分组验证纳入完整门禁。

整套门禁识别出一处微信 fixture 使用任意 prompt 标签。总控批准将该 fixture 标签改为真实注册的 v1 模板，保留 HTTP fixture、候选正文和未知发送测试断言；未知版本拒绝的单元测试同时保留，不通过放宽校验消除失败。
